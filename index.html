TP 1 – Installation, configuration et administration d'un système d'exploitation orienté poste de travail : Windows 11 Professionnel

Matière : SISR (réseaux)

Objectif
  • Maîtriser les étapes d'installation, de configuration et d'administration d'un système d'exploitation orienté poste de travail : Windows 11 Professionnel.
Ce que j'ai fait
  • Installation de Windows 11 sur une machine virtuelle
  • Configuration des paramètres système et réseau
  • Création et gestion des comptes utilisateurs
  • Installation et configuration des logiciels nécessaires
  • Réalisation de tests pour vérifier le bon fonctionnement du système
Difficultés rencontrées
  • Problème de compatibilité avec certains logiciels : j'ai recherché des alternatives compatibles.
  • Erreur lors de l'installation de Windows 11 : j'ai consulté la documentation officielle et suivi les étapes de dépannage. S'agissant d'un problème technique, j'ai finalement décidé de passer sur Windows 10 Professionnel.
  • Problèmes de réseau : j'ai vérifié les paramètres et redémarré les services réseau.
